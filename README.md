# 🍅 Pomodoreo 番茄钟

一个轻量、零第三方依赖的桌面番茄钟应用，基于 Python 标准库 `tkinter` 构建，双击即可运行。

## ✨ 功能特性

- **标准番茄工作法**：专注（默认 25 分钟）、短休息（5 分钟）、长休息（15 分钟）
- **智能循环**：每完成 4 个专注自动进入长休息
- **圆形进度环**：随剩余时间动态收缩的彩色进度指示
- **专注进度圆点**：直观展示当前循环内的专注进度
- **开始 / 暂停 / 重置 / 跳过**：灵活控制计时节奏
- **完成提醒**：阶段结束时蜂鸣提示并窗口闪动提醒
- **窗口置顶**：一键将窗口保持在最前
- **自定义设置**：专注与休息时长、长休息间隔均可调整，自动保存

## 🚀 快速开始

### 环境要求

- Python 3.x
- Windows 下自动启用蜂鸣提示音；macOS / Linux 可运行但无声（自动降级处理）

### 运行

直接双击 `番茄钟.pyw`（无命令行窗口），或命令行运行：

```bash
python pomodoro.py
```

## ⚙️ 配置

配置保存在同目录下的 `pomodoro_config.json`，也可在应用内"设置"窗口修改并自动保存：

```json
{
  "work": 25,        // 专注时长（分钟）
  "short_break": 5,  // 短休息时长（分钟）
  "long_break": 15,  // 长休息时长（分钟）
  "long_every": 4,   // 每几个专注后进入长休息
  "on_top": false    // 窗口置顶
}
```

## 📁 项目结构

```
pomodoreo/
├── pomodoro.py            # 主程序（图形界面 + 计时逻辑）
├── 番茄钟.pyw             # Windows 双击启动入口（不弹出命令行窗口）
├── pomodoro_config.json   # 配置文件（应用启动时读取，修改后自动写回）
└── .gitignore             # 忽略 Python 缓存文件
```

## 🛠 技术说明

- 使用 Python 标准库 `tkinter`，**零第三方依赖**
- `winsound` 可选导入：Windows 提供蜂鸣提示音，其他平台自动降级
- 配置自动持久化到本地 JSON 文件，窗口关闭时保存
- 界面配色随状态切换：专注（红）、短休息（绿）、长休息（蓝）
